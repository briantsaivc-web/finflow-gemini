# 夢想圈資料庫

## 資料規模

- 4 大類：品味、挑戰、旅程、傳承
- 8 張夢想卡
- 每張夢想卡 20 個候選里程碑
- 全資料庫共 160 筆
- 每位玩家開局從自己的夢想卡隨機抽出 5 筆，不重複

抽選結果保存在 `player.dreamMilestoneIds`。同一個遊戲種子、座位與夢想卡會得到相同結果；存檔、重播及多人同步亦沿用同一組 ID。

## 圖片欄位

每筆里程碑均預留：

- `imageType`：`real` 或 `ai`
- `imageFile`：Repository 內的相對路徑
- `imageQuery`：實景圖片搜尋字串
- `imagePrompt`：AI 圖片生成提示
- `sourceUrl`：原始來源頁
- `license`：授權條款
- `author`：作者／攝影者

## 圖片上架規則

1. 本版 160 張素材均採 AI 情境插畫，避免把生成內容誤認為景點或店家實景。
2. 料理與旅行圖片只呈現地域及主題概念，不重製真實店面、招牌、商標、人物肖像或特定擺盤。
3. AI 圖不得模仿特定在世藝術家；每筆均須保留生成提示、來源、作者及授權資料。
4. 未完成授權欄位的圖片不得放進公開版本。
5. 圖片檔統一使用 WebP，建議比例 16:9，並保留原始來源紀錄。

## 相容性

夢想卡仍保留舊版 `milestones` 前五筆文字，供舊擴充模組讀取；新版遊戲邏輯以 `milestonePool` 與 `dreamMilestoneIds` 為準。
